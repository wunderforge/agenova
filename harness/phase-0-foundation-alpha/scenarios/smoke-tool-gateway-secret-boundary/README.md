# Smoke: Tool Gateway Secret Boundary

This Phase 0 scenario is a static placeholder for the future Tool Gateway boundary.

The fixture keeps the upstream token in a gateway-owned secret/policy shape and does not expose an upstream token environment variable to the sandbox template.

This is not a complete security proof. Behavior-level evidence belongs to the Tool Gateway phase.

This scenario does not prove Pod isolation, node isolation, gateway authentication, or workload identity security.
