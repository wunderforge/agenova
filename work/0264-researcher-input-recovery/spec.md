# Tool-input recovery and failure presentation

A tool input is the scalar value expected by its published catalog route. Fixed-choice values are exact; free-text remains nonempty and bounded. The reference Agent may show a complete retry example for a known operation/scope, but may not rewrite model output or dispatch until a new real model action passes normal validation and exchange correlation.

The single-object diagnostics grammar keeps all required fields. A fixed-only catalog adds an input enum including the finish empty string. Mixed free-text/fixed catalogs describe per-operation values without restricting valid web queries or URLs. Legacy provider schemas do not change.

Terminal no-final-result plus the most recent unrecovered ActionValidated error is a validation failure, not a Gateway denial. UI may derive a cause/link from existing facts without rewriting history. Successful actions or observations and provider/authority failures supersede older retries. No arbitrary Agent feedback or raw model text is promoted into a trusted top-level failure message.

Keep the existing neutral requested/granted table and one concise warning with Evidence. Details belong under the evidence record. No API shape or claim lifecycle changes.
