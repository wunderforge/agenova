Advanced permissions and underlying roles

Owner is the protected account owner, not an everyday access choice. Existing project-only administrators and custom account/project combinations remain supported.

Developer maps to Account Member + Project Member. Read-only maps to Account Member + Project Viewer. Team administrator maps to Account Admin + Project Admin for the selected project; it never grants access to every project.

Deployment access (Platform Operator) authorizes CLI operations for a named installation and also requires the operator’s own AWS/Kubernetes identity.

Governance access (Governance Admin) authorizes immutable Policy/Template registration for a named account or project. Neither advanced duty grants Work access or cloud credentials.

All existing server-side checks remain in force. Task authority is still limited by Policy and Template.
